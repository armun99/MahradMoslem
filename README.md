# Summit Authority

Create a premium, modern personal portfolio website for a professional rock climbing expert, coach, author, and accomplished climber.

Overall Concept

The website should present him as a highly respected authority in rock climbing — someone with years of experience, major achievements, coaching expertise, and published books.

The visual identity should feel:

Adventurous

Powerful

Premium

Minimal

Authentic

Athletic

Inspirational

Avoid the typical generic portfolio/template look. The website should feel like the personal website of an elite climber, professional coach, and respected author.

Visual Direction

Use a dark, cinematic visual style inspired by mountains, cliffs, climbing walls, and outdoor adventure.

Color palette:

Deep charcoal / almost black background

Off-white typography

Earthy stone / gray tones

A subtle orange or burnt-orange accent inspired by climbing gear and sunset on rock

Use large, dramatic photography of rock climbing, mountains, cliffs, climbing ropes, chalk, and outdoor landscapes.

Photography should feel authentic and documentary-like rather than stock-photo corporate imagery.

Use subtle textures inspired by rock surfaces.

Typography:

Strong, bold display font for headings

Clean modern sans-serif for body text

Large typography and generous whitespace

Strong visual hierarchy

Animations should be subtle and premium:

Smooth scroll

Image reveal animations

Text fade/slide animations

Subtle parallax on hero imagery

Hover interactions on cards

Avoid excessive animations

The website must be fully responsive and look excellent on desktop, tablet, and mobile.

Navigation

Create a sticky navigation bar with:

Home

About

Achievements

Books

Coaching

Gallery

Contact

Include a prominent CTA button:

"Work With Me"

On mobile, use a clean hamburger menu.

HERO SECTION

Create a dramatic full-screen hero section.

Use a powerful photograph/video-style background showing the coach climbing a spectacular rock face or mountain.

Overlay a dark cinematic gradient to ensure text readability.

Large headline:

"CLIMB HIGHER.
PUSH FURTHER."

Subtitle:

"Professional Rock Climber · Coach · Author"

Add a short introduction:

"Decades of experience on the wall and in the mountains, helping climbers push beyond their limits."

Primary CTA:

"Explore My Journey"

Secondary CTA:

"Work With Me"

Add a subtle scroll indicator at the bottom.

The hero should immediately communicate expertise, adventure, and authority.

INTRO / ABOUT SECTION

Create an elegant split-screen section.

Left:
A large portrait/action photograph of the coach.

Right:
Heading:

"More Than a Climber.
A Lifelong Student of the Mountain."

Write a compelling biography describing him as:

An experienced rock climber

Professional climbing coach

Author of climbing books

Mentor to younger climbers

Someone who has dedicated his life to climbing and outdoor adventure

Do not invent specific facts, achievements, dates, or book titles. Use realistic placeholder content where information is not yet provided.

Include a CTA:

"Read My Story"

ACHIEVEMENTS SECTION

Create a visually impressive achievements section.

Use large numbers/statistics with animated counters.

Example placeholders:

"25+"
Years of Climbing

"100+"
Major Ascents

"10+"
National / International Achievements

"3"
Published Books

These values should be easy to replace with the coach's real information.

Below the statistics, create a chronological timeline of his most important career achievements.

Each timeline item should contain:

Year
Achievement title
Short description

Example:

2005
"First Major Expedition"
Short description about the achievement.

2010
"National Championship"
Short description.

2018
"Published First Climbing Book"
Short description.

2024
"Mentoring the Next Generation"
Short description.

Make the timeline visually connected and elegant.

BOOKS SECTION

Create a premium "Books" section because his authorship is an important part of his identity.

Heading:

"Knowledge Worth Passing On"

Subtitle:

"Years on the rock, distilled into books for the next generation of climbers."

Display each book as a beautiful large book card.

Each card should include:

Book cover

Title

Publication year

Short description

Topics covered

"Learn More" button

Use realistic placeholder book covers if actual covers are not provided, but structure the UI so real book cover images can easily be inserted later.

Create a featured book with a larger layout:

Book cover on the left.

On the right:

Book title

Author name

Description

Key topics

"View Book" CTA

COACHING SECTION

Create a section dedicated to his coaching philosophy.

Heading:

"Climbing Is Not Just About Strength."

Explain that successful climbing requires a combination of:

Technique

Strength

Mental discipline

Movement

Strategy

Patience

Understanding your own limits

Create 4–6 coaching cards:

Climbing Technique
Strength & Conditioning
Mental Training
Route Reading
Outdoor Safety
Performance Coaching

Each card should have a minimal icon and short description.

Include CTA:

"Train With Me"

PHILOSOPHY SECTION

Create a cinematic quote section with a large background image of mountains/cliffs.

Display a powerful quote:

"The goal isn't simply to reach the top.
It's to become the climber capable of getting there."

Make this section visually emotional and memorable.

Include the coach's name beneath the quote.

GALLERY

Create a premium masonry-style photography gallery.

Categories:

All
Climbing
Mountains
Expeditions
Coaching
Behind the Scenes

Images should showcase:

Outdoor climbing

Rock faces

Mountains

Expeditions

Training

Coaching students

Competitions

Personal moments

Clicking an image should open a beautiful fullscreen lightbox.

EXPEDITIONS / JOURNEY SECTION

Create an interactive section showing important climbing expeditions and journeys.

Each expedition should include:

Location

Year

Mountain / route

Difficulty

Short story

Photography

Use a visual map-inspired layout if appropriate.

TESTIMONIALS

Create a testimonials section from students, climbers, colleagues, and people he has coached.

Each testimonial should include:

Quote

Person's name

Role / relationship

Optional photo

Use 3–5 testimonials as placeholders.

CONTACT / WORK WITH ME

Create a strong final CTA section.

Heading:

"Ready to Take Your Climbing Further?"

Text:

"Whether you're starting your climbing journey or preparing for your next major ascent, let's talk."

Include a contact form:

Name
Email
Phone
Experience Level
Message

CTA:

"Get In Touch"

Also include social media links, especially Instagram, YouTube, and other relevant climbing platforms.

FOOTER

Minimal dark footer.

Include:

Coach's name / personal brand

Short description

Navigation

Social links

Contact information

Copyright

Add a small line:

"Built around a life on the rock."

UX REQUIREMENTS

The website should feel like a premium personal brand website, not a corporate website.

Prioritize:

Photography

Storytelling

Achievements

Books

Coaching expertise

Personal credibility

Use large visual sections and strong typography.

Avoid:

Generic SaaS-style cards

Excessive rounded corners

Excessive gradients

Overly colorful UI

Generic stock photography

Too many UI elements

Crowded layouts

The website should have a strong editorial / outdoor-adventure aesthetic.

Create reusable components and keep the code clean and maintainable.

Use placeholder content and images where information is missing, but make the structure ready for replacing them with the coach's real achievements, books, photographs, biography, and statistics.

The final result should feel like the official website of an internationally respected rock climbing expert, athlete, coach, and author.
